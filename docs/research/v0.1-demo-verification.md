## 6. 端到端测试大纲（**最小 6 条 e2e**）

来源：[CLAUDE.md 第 2.4 节](../CLAUDE.md) "每个 MVP 场景至少 1 个端到端测试"

### 6.1 E1：单 session 内进度可视化（场景 A）

```gherkin
Given 用户在 DSH web 启动一个空 skyaxis session
When 用户开启 P3 shell.overlay 拓扑视图
And 在 conversation 中发 1 个 turn（含 2 个 tool calls）
Then SUB.5 时间线显示 1 个 turn、2 个 tool call 节点
And Task DAG 节点状态从 pending → running → done
And 拓扑视图节点显示最新状态
And P3 overlay ESC 关闭 + restoreFocus 回到 trigger
```

**实现要点**：[调研报告 5 § 8](trajectory-merger-algorithm.md) turn 边界配对 + [调研报告 6 § 14](cordis-effect-lifecycle.md) cordis effect + [调研报告 8 § 4](canvas-interaction-nfr.md) React Flow 集成

### 6.2 E2：subagent 派生链可视化（场景 A 纵深补强 / SUB.1）

```gherkin
Given root session 已派生 3 个 subagent（其中 1 个已 running）
When 用户在 P3 overlay 拓扑视图查看
Then 拓扑显示 1 root + 3 子节点
And 1 个子节点显示 running state
And 子节点 metadata 显示 mode（one-shot / continuable）/ label
And hover 150ms 显示 tooltip（active duration 实时刷新 1s）
```

### 6.3 E3：跨 session 聚合列表（场景 C）

```gherkin
Given 用户历史有 12 个 session（status 混合）
When 用户进入 C 多 session 总览
Then 显示 12 个 session 卡片
And 每个卡片显示 status / 当前 task / 进度 / sub-agent 数
And 按 status 过滤（active / idle / done）生效
And 按标签过滤生效
```

### 6.4 E4：会话切换保持 overlay（[ADR 0011 § 5.5](decisions/0011-shell.overlay浮层实施约束.md) C.5）

```gherkin
Given P3 shell.overlay 拓扑视图已打开
When 用户切换 conversation（main panel 切到不同 session）
Then overlay 仍保持显示
And overlay 内拓扑节点更新为新 session 的 subagent tree
```

### 6.5 E5：a11y 键盘完整流程（[调研报告 8 § 4](canvas-interaction-nfr.md)）

```gherkin
Given P3 overlay 拓扑视图打开
When 用户 Tab → 焦点到第一个节点
And 用户 ArrowDown → 焦点到下一个节点
And 用户 Enter → 进入会话详情（P2 rightbar tab 打开）
And 用户 Esc → 关闭 P2 tab，焦点回到 topology 节点
And 用户 Esc → 关闭 overlay，焦点回到 trigger 按钮
Then 焦点链：trigger → 节点 → P2 tab → 节点 → trigger
```

### 6.6 E6：observe-only 边界（[调研报告 6 § 10](cordis-effect-lifecycle.md) + [调研报告 7 § 11](session-projection-cache.md)）

```gherkin
Given 加载 skyaxis plugin

And CI typecheck 跑通
Then 任何 `ctx.subagents.register(...)` / `ctx.sessionProjections.register(...)` 等 mutation 调用都被 lint 拒绝
And `ctx.provide('sessions', ...)` 等 provide 重名抛错（启动时报错）
And cordis effect cleanup 配对（dispose 后所有注册项消失，HMR-safety test 通过）
```
