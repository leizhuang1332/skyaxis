## 0. 白话摘要

**场景**：S2 已把需求拆成工作包并批准（硬门①）。进入 S3 后，点开一个 WP 详情，「生成工作包任务书→投递并发送」，AI 会话立刻开始写代码——「待计划→计划已批准」两列状态被整个跳过。

**答案**：(1) 空转是结构性的，不是用法偏差：dev 任务书五段里**没有约束段**（对比分析/规划族全有「严格只读」），投递即执行；计划今天**唯一写入通道是人手 textarea**（0006 权责表设计的「AI 起草计划✓」通道从未实现）；于是「批准计划」变成自己批自己写的字，四权之一空转；0016 两轮实机验收记录在案的用户行为就是跳过直投（当时的修法是把收取门后撤迁就现实，而非把计划链做实）。(2) 补法=用户提案的 WP 两步化：新增「工作包规划任务书」（只读探索+写 WP 计划文件）→ 工作台收取为 `plans[]` 草稿（`planned→plan-draft` 同 save 原子）→ 人**批准计划**（硬门②语义零变化，但从此批的是 AI 的提议而非自稿）→ 再生成开发任务书（嵌已批准计划）投递。机器几乎全在（plans[] 版本链/批准按钮/文件通道+收取管道/失效链），新增只有三件：wp-plan purpose 任务书、收取→plans[] seed、dev 任务书的状态驱动分层。

**意义**：0006 P2「人握门禁」四权中的批准计划权从橡皮图章变成真门；dev 会话（最贵动作：改工作区、长会话）获得业界标配的 plan-approve gate；0016 刀〇侦察证实 dev 会话本就自制 todo/write——本设计只是把会话内不可见的自制计划提升为可审可批可版本化的账本对象；「待计划」列名名实相符。

## 3. 论证：维持现状 vs WP 两步化

**五条支持两步化**：

- A **四权落空**（主论证）：硬门②今天批的是人自己 textarea 里的字；AI 起草后「批准计划」才成为对他人提议的真实裁决——与 S1 裁决发现、S2 采纳规划、S4 裁决评审同构，补齐工作台「AI 提议→人裁决」模式在 WP 层的最后一个缺口。
- B **现实行为证据**：0016 两轮验收记录在案的 100% 跳过率。一道门被所有人跳过时，修法不是删门（0016 已试过门后撤），而是给门配上值得过的路。
- C **最贵动作配执行前审**：dev 会话改工作区、跑长会话，返工成本全链最高；业界 plan-approve gate 对此标配（§2）。
- D **显性化既有行为**：侦察数据证明 AI 已自制 todo；提升为 plans[] 草稿只是把它从会话内存搬进账本。
- E **上下文蒸馏红利**：规划会话的探索结论落为计划文件→批准后全文嵌入 dev 任务书（sow.ts:271-275 现成）→dev 会话免重新漫游（0011 论证 C「知识蒸发」的 WP 级复制；Claude Code 规划/执行上下文隔离同型）。

**四条反方与回应**：

- ① 业界 agent 产品 todo 全自管无门——成立，但其 todo 不进治理账本；skyaxis 的 plans[] 进账本受治理（§2 决定性对照），且 0006 权责表本就设计了 AI 起草通道（E3），实现它是对齐原设计而非背离业界。
- ② 单人仪式成本（BMAD「没参与思考的人才需要批准级流程」）——真风险；缓解=跳过路径保留（D4 状态驱动分层，非硬门）+ 人工直写通道保留（D6）+「一段话计划也是计划」。
- ③ 两会话上下文重建成本——缓解=已批准计划即蒸馏物、全文嵌入 dev 任务书（E）。
- ④ 失效链膨胀（上游变→WP 计划 stale）——列非目标（§5），本轮不接。

**skyaxis 特有约束**（0011 同款物理限制）：投递=会话草稿、0017 起 prompt 直启人握点击——会话中途暂停求批准物理上不可能，中间门只能=两次投递。这与两会案天然对齐。

## 5. 边界与非目标

- **不做一会话两产物**（规划+开发同会话）——中间门蒸发，退化回一步只多一个工件（0011 §5 同款红线）。
- **不接失效链**（上游基线/规划文档变→WP 计划标 stale）——0006 §7.6 的挂账继续挂；重拆分是硬门①大事本就走显式重流程，本轮不自动化。
- **WP 规划不改边界、不增删 covers**——D5 红线；越界诉求走发现通道。
- **declare 体系不加 plan 键**——纯文件交付（plan purpose 先例）；knowledge 候选仍走 ⑤ 手动。
- **不自动化「批准后自动投递开发任务书」**——两次投递两个人握动作，不合并（四权）。
- **不退役/不改硬门②语义**——approvePlan 的尾草稿锁、批准盖章、重基线路径全部原样；唯一变化是草稿的作者多了 AI。
