# DSH v0.2.1-rc.3 升级影响分析报告（skyaxis 侧）

- 日期：2026-10-26
- 范围：skyaxis 全部 `@deepseek-ai/*` 依赖 0.1.5-rc.2 → 0.2.1-rc.3 升级影响审计
- 方法：升级指南全读 + 契约源码抽读 + 消费面逐符号审计（grep 级预检，非 tsc 实测）
- 拍板：2026-10-26 用户确认全部决策点按推荐执行（见第四节）

## 白话摘要

**场景**：skyaxis 是挂在 DSH Web GUI 上的双面插件，全部 `@deepseek-ai/*` 依赖钉在 0.1.5-rc.2；宿主已升到 0.2.1-rc.3，中间隔了 0.1.6 / 0.1.7 / 0.2.0 / 0.2.1 四条版本线。

**答案**：需要改造，但是**小刀量级**。逐符号审计了全部消费面后，硬断点只有一处——`dsh-client-ui-primitives` 的 **13 个图标组件改名**（尺寸后缀换字重后缀，机械替换可解）；其余 14 个消费包的命名符号、子路径导出、patch 清单字段、workspace 注册语义**全部存活**。真正的设计决策只有两个：①新版宿主的 `sessions.create` 会**复用空白会话**（渗入了 skyaxis 投递路径依赖的契约层）；②`engines.dsh` 从「参考项」变成**唯一兼容判定**，声明范围等于支持承诺。两者已拍板（接受复用+回归钉；收紧地板）。

**意义**：这不升级不是「锦上添花」而是「止损」——新版宿主上 engines 放行加载、但旧 client bundle 的 13 个图标导入在浏览器模块表里已不存在，**渲染即碎**。改造约一个立项轮（0033）可完成，无架构级迁移。

## 二、影响判定（逐项，含证据）

### 2.1 硬断点（编译/运行时必改）

**P1 · ui-primitives 图标家族改名（13 个）**。符号审计：26 个导入符号中 13 个失踪，全部是 `Icon<Name>Outline<Size>`：

| 旧名（0.1.5-rc.2） | 新名（0.2.1-rc.3，四态取其一） |
|---|---|
| IconChevronDownOutline14 / IconChevronLeftOutline14 | IconChevronDown/LeftOutline**Regular**（或 Medium） |
| IconChecklistOutline14 | IconChecklistOutlineRegular / Medium |
| IconClockOutline16、IconCloseOutline16、IconDatabaseOutline16、IconDownloadOutline16、IconEllipsisOutline16、IconFolderOpenOutline16、IconListPenOutline16、IconPaperclipOutline16、IconPlusOutline16、IconSearchOutline16 | 同字形 + OutlineRegular / OutlineMedium |
新命名在 `packages/client/ui-primitives/src/icons/index.tsx`，每字形有 `Base/Artwork/Medium/Regular` 四态；DSH 自家先例（locale 包 LanguageRow.tsx）用 **Regular** 档。`FileTypeIcon` 及其余 13 个符号（Button/Input/Modal/Menu/MenuEntry/MarkdownText/RiskConfirmation/StateDot/Tag/fileSizeText/relativeTime/writeClipboard）**全部存活**。注：这是**运行时断点**——skyaxis 的 client bundle 在浏览器从 web shell 模块表解析这些名字，新宿主上渲染即碎。

### 2.2 行为契约变化（需决策/回归，非必然改码）

**P2 · `sessions.create` 空白会话复用**。0.2.1-rc.2 起契约（api/session-controller `client/contract/sessions.ts:83-91`）：

```ts
create(opts?: { workspaceId?, cwd?, sessionId?, agentPreset? }): Promise<SessionId>
// "The Host reuses the named blank Session while it is reusable and otherwise creates another"
```

配套：快照加 `blank: boolean`；**会话列表默认隐藏空白会话**。skyaxis 的 [delivery.ts](../../src/client/workbench/delivery.ts) 用最小鸭子接口面包 `ctx.sessions.create`——结构兼容、可编译，但语义变化：投递可能落进工作区内已存在的用户草稿空白会话；watcher/声明卡的会话列表不再看到空白会话。指南给的隔离手段是传 `agentPreset`（跳过其他 preset 的空白会话）。
**已验证未变的两条锚**：`workspaces.create` 的 resolveByPath create-or-resolve 原样（workspace-controller/src/commands.ts:45-53，注册幂等假设成立）；「create 只认 workspaceId 挂载侧栏」行为注释仍与契约一致。
**P3 · `engines.dsh` 成为唯一兼容判定**（v0.2.1-alpha.3 指南）：过去 peer 声明参与判定，现在 engines.dsh 单独决定、peer 被忽略（仅缺 engines 时回退 peer）。skyaxis 的 `>=0.1.5-rc.2` 覆盖 0.2.1-rc.3（能加载），但升级后代码只对新版验证过——**声明宽度 = 支持承诺**，且 client bundle 单一构建无法双栈兼容新旧图标名，诚实地板应收紧（已拍板收紧，见 D1）。

**P4 · 子代理 activation 模型重构**（alpha.1）：委派结果从「前台输出 / `{kind:'background', jobId}`」改为 `{kind:'activation', subagentId}` + 完成通知。skyaxis 任务图从 **lineage 快照**建子树（[connector.ts](../../src/client/task-graph/connector.ts)，`buildSubagentGraph(list)`，`subagent:*` 命名空间），不消费工具结果形态（job_output/jobId 全仓零引用）——**无直接代码冲击，需行为回归**（activation 会话在列表/lineage 中的呈现是否照旧）。

**P5 · 会话/宿主周边（记档级）**：新会话不保证用当前 preset 定义（重启 Host 后装配）；JobId 改 `<kind>-<uuid16>` 格式（skyaxis 零消费）；`from-default-profile` 变**替换式**（会删已有 profile 的 patch/插件——运维注意）；`webRuntime→webStartup`（skyaxis inject 清单无此服务，用户自有 overlay 才受影响）；`DSH_TOOLS_MODE=both` 被拒（skyaxis 不配 tools mode）。

### 2.3 明确无影响（证据在案）

| 变更 | skyaxis 侧证据 |
|---|---|
| `{{cwd}}` 模板变量移除 | 全仓零引用 |
| `./invariant` 子路径全退役 | skyaxis 零消费 DSH 侧 invariant 子路径；自有 [invariant.ts](../../src/invariant.ts) 导出自包含（`@deepseek-ai/*/invariant`、`dsh-invariants` 零导入） |
| Schedule bundle 退役 | 净利好：0.2.0 起 dsh-web-app 在每个 Web profile 默认挂 `schedule`+`ui-schedule`——skyaxis 的 Host cron 依赖开箱即用；patch 无 time-context 行（无「不匹配条目」警告） |
| 子路径插件展示清单改版 | skyaxis 只导出根 `./package.json`（根插件保留该机制），无 `<子路径>/package.json` 导出 |
| 实验包显式组合新规 | patch 本就是自家行的完整 insert，非「启用已移除行」型 |
| jsonl 持久化插件化 | skyaxis 未消费该包；服务 API 与存储文件不变 |
| `dsh plugin` 参数位置新规 | README/patch 注释的命令已是 `dsh plugin --profile <name> add ...` 顺序，合规 |
| `dsh.bundle.patch` 清单字段 | boot/app-boot/src/profile.ts 原样读取（字符串或列表） |
| 消费的 `/client` 等子路径导出 | api-remotes、locale、ui-renderer、connection 的 `./client` 全部存续 |

## 四、拍板记档（2026-10-26 用户确认：均按推荐）

- **D1 engines 地板 → A**：收紧为 `>=0.2.1-rc.3`。理由：新规则下 engines 是唯一判定，宽域 = 对未验证版本的背书；图标改名使旧宿主上 client bundle 本就无法双栈兼容。

- **D4 零引用 devDeps（dsh-commands、dsh-client-ui-sidebar、dsh-client-test-runtime）→ 本轮不动**：如要剪另立项点名（合并范围纪律）。
