# 决策 0022：规划会话投递即绑（sessions[] 用途扩 'wp-plan'）

> 日期：2026-10-21
> 背景：用户实机报告——待计划 WP「生成工作包规划任务书」→「投递并发送」后，WP 详情「关联会话」无新投递会话记录（会话实际已创建并运行，DSH 侧栏可见）；对照 plan-approved「开始开发」投递即入关联会话。
> 状态：**已拍板**——用户 2026-10-21 选题「投递即绑关联会话（推荐）」。修订 [决策 0018](0018-工作包规划两步化决策.md) D8「不绑 sessions[]」子口径。
> 实施落 [milestones/0022](../milestones/0022-规划会话投递即绑实施计划.md)。

## 缺口取证（file:line）

**层一（设计口径，主因）**：0018 D8 拍板规划会话不绑 `sessions[]`——投递回只写 `planSeed.session` 溯源指针（view.tsx wp-plan 臂 → `recordWpPlanSession`，host 明言不触 sessions[]）；开发路径则投递即绑（`startWorkPackage → bindDevSession`）。两边各自正确、行为不对称，不对称即用户报告的「不自动关联」。

**层二（可见性缺口，加重感知）**：溯源行的唯一 UI（计划节「来源会话」小字）嵌在 `plans.length === 0 ? 「尚无计划」 : …` 分支内——**投递成功到 AI 写完计划文件被收取前 plans 为空，该行不可见**，状态也未翻；整个窗口内 WP 详情对在跑会话零痕迹。

**附带盲区**：view 层从未有用例钉 wp-plan 投递臂接线（host 层只钉指针语义）——本轮连带补。

## D1 投递即绑 sessions[]（已拍板）

`sessions[]` 用途枚举扩 `'wp-plan'`（协议/存储/输入双侧同步），wp-plan 投递成功（sent）在指针之外**经普通 `bindSession` 动作**追加绑定行——「关联会话」面与开发路径同形：投递即出现可点入行（状态 chip 实时），标签「规划」/「wp-plan」。`recordWpPlanSession` 动作**零改动**（指针语义原样：同会话 unchanged / 异会话替换+清戳重臂）——绑定不搭车进该动作，走既有动作分立两写（0018 合并轮 dev 臂串行先例）。

**次序与降级**：指针先行（布防收取 watcher），绑定后行（`bindWpPlanSession` 孪生带一次有界 409 重试）；绑定彻底失败只退回 0022 前现状（watcher 仍 armed），诚实降级。

## D2 指针与收取链零改动（连带拍板）

`planSeed.session` 仍是收取 watcher 的臂与收取回执溯源（哈希主锚/幂等语义全部原样）；「来源会话」小字行的 plans 非空门维持原样（它表述收取回执溯源；**即时可见性由新「规划」行承担**——层二缺口由 D1 顺带消除，不另动计划节）。

## 连带记档

- **消费面行为变化（诚实面）**：规划会话自此计入看板卡 `{n} 会话`、进入 execution-section 会话行（裸串渲染）、被排除出 declare 导入/评审抓取/知识库选择器的候选集与 dev-watcher 标题 pass 的 bound 集（纯文件通道会话本不携 declare/评审内容，排除诚实；其头行「工作包规划任务书」也不匹配 dev 标题正则）。
- **手动 picker 不开放「规划」用途**：session-picker 候选维持三用途——手动绑规划行不写 planSeed 指针、不驱动收取 watcher（半真 UI）；降级投递的修复正路是重投递。Record 标签映射补 'wp-plan' 键仅类型完备（编译强制）。
- **账本语义**：append-only 维持；重规划（异会话重投递）指针替换+新「规划」行累积——与 dev 补投累积同语义。同会话异用途 ⇒ 400（客户端 bug 面，既有守卫原样）。
- **词典** +1 键四处登记（`session.purposeWpPlan`：zh「规划」/en「wp-plan」——en 沿用途裸词先例）。

## 不动清单

`recordWpPlanSession` host 动作与收取 watcher；「来源会话」行的 plans 非空门；session-picker 候选数组；降级（sent=false）投递不绑不记（0017 刀二 shell 口径）；wp-plan 无标题/内容寻址兜底通道（不造，记边界）；wire/host 动作族结构；需求级 'plan' purpose（S2）维持不绑——本轮只动用户点名的 wp-plan；0018 状态分层/0019 返工链/0020 内容区/0021 渲染面。
