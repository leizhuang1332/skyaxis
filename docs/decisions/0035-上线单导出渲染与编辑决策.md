# skyaxis — decision 0035：上线单导出渲染与编辑（SheetExportModal 双面消费）

> 日期：2026-10-27
> 背景：用户同日两连拍板——①「上线单展示要渲染markdown」（导出 Modal 裸 `<pre>` 显示 `## 配置（2）` 原文）；②「支持编辑」（渲染落地后追加）。两拍板合力把上线单导出面从 0006 的只读 pre 推到 0009/0021 的「渲染默认＋编辑切换」双面形态。
> 拍板：用户 2026-10-27 实机验收通过（§五四条）。

## 白话摘要

导出上线单弹出的 Modal 现在默认把 markdown 渲染成排版好的页面（标题、分组、代码块），点「编辑」切成文本域可以直接改，改完点「预览」看渲染效果，「恢复生成内容」一键回到台账现算的原文。复制和下载发的就是你在面上看到的这份文本（改过发改过的）。知识库导出和需求理解摘要导出共用这个 Modal 但没被点名，保持原来的纯文本只读样子不变。

## 一、拍板与边界（0021 D2 的限定覆盖）

0021 D2 曾拍板「sheet-export-modal 的 `<pre>` 是所见即所复制纪律且非任务书——不动」。本轮用户点名**上线单消费面**，该边界对且仅对该消费面退役：所见即所复制演化为所见即所发（0009 语义——每一面展示的都是复制/下载动词要用的同一 text 变量，动词字节随用户编辑走）。未点名消费面（知识导出 P5a、需求理解摘要 0008）原样保留 pre-only 形态，各有测试缺席钉。

## 二、设计要点

1. **prop 门控**：`SheetExportModal` 新增 `renderMarkdown?: boolean`——上线单（deliver-section）传，缺席 = 0006 pre-only 面 DOM 原样（共享 shell 不动未点名消费面）。
2. **双面**（sow-modal 0009+0021 双胞胎，全复用 sowEditBar/sowEditor/sowRendered 词汇，零新 CSS）：渲染面默认（`MarkdownText` + labels memo 稳定引用）；「编辑」钮切 `sowEditor` textarea；钮文案 md.edit/md.preview 随面翻转（0021 既有键）。
3. **用户编辑盖过 live build**（0009 契约）：`editedText ?? sheet`；脏编辑跨面切换持久；重开复位渲染默认面＋清编辑（open effect）。脏编辑时 footer 出「恢复生成内容」（`sheet.resetEdit`，sow.resetEdit 同文案）。
4. **动词取文**：复制/下载注入均收 `text`（编辑后的文本）；注入 seam（copy/download props）契约不变。
5. **同日两步的词典净额**：渲染轮先加 md.rendered/md.source（只读源码面切换钮）；编辑轮按 0009 先例「pre 变 textarea」后该只读面退役，两键即日清死键；净额 −2+1=**+1 键**（sheet.resetEdit）。三面登记：dictionary（interface/zh/en）+ register.tsx `LocaleKeysOf` 联合 + register.spec key-set 钉。
