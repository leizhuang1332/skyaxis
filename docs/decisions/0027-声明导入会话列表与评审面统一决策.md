# skyaxis — decision 0027：声明导入会话列表与评审面统一

> 日期：2026-10-22
> 背景：用户验收追加——「⑤ 交付 - 导入声明 中的选择会话列表改造：要求和 ④ 评审 - 导入报告 中的会话列表保持一致，风格要统一」。declare 导入弹窗此前在 0024 不动清单里（「未点名」），本轮点名补齐。
> 现状取证（file:line 见会话记录）：① 控件=原生 `<select>`——正是 0024 D3-B 在评审面修掉的同一缺陷（宿主 webview 渲染弹层、超可视高度不滚、低位会话不可达）；② 候选=仅 WP 绑定会话（declare-import-modal.tsx boundSessions 并集），不查存活面、无空壳过滤、无工作区收窄；③ 空态词条 `declare.noBoundSessions`、标签「从绑定会话抓取」均为绑定限定口径。另：`declareFetch` 与 `reviewFetch` 同引擎同降级包络（endpoint.ts blockFetchFlow），且**读持久化日志——已归档会话抓得到**（归档只从列表隐藏，日志仍在），这是现状下拉包含离列表绑定会话的真实能力。

## 二、实现与连带口径

1. **控件**：pickerList 滚动单选列表（radio 行＋StateDot＋max-height 240px，`name="declare-fetch-session"`）替代原生 select；「请选择」空选项退役（radio 未选即未选，抓取按钮随选区禁用）；抓取按钮移列表下方；radio 换选清 fetchError（对齐评审面）。
2. **数据穿线**：DeclareImportModal 新增必填 `workspacePath`——交付节入口直取 `props.requirement.workspacePath`；卡片入口 view → BoardSection → WorkPackageDialog → DeclarationCard 三跳穿线（显式 props，task-graph 纪律；必填防未来调用点漏传静默重开全机器列表）。
3. **词典净零**：`declare.noBoundSessions` 退役 → `declare.noSessions`（zh「当前工作区没有可抓取的会话（从未运行的空壳不算）；也可直接粘贴。」——与 review.noSessions 同文）；`declare.sessionLabel` 改义「从会话抓取」（en Fetch from a session）；`declare.sessionPlaceholder` 转列表上方提示行（键复用零新增）。五处登记连带（接口/zh/en/LocaleNamespaceMap/register.spec 字典序位）。
4. **空态**：无绑定且工作区零可抓取（含全外来）⇒ 同一 noSessions 提示；sessions face 缺席 ⇒ 抓取行整块不渲染（原样）。
5. **置顶序语义**：绑定并集先行（Set 去重），存活面其余（过滤后）随后；绑定行不参与空壳过滤与 cwd 收窄（账本事实优先，D2）。

## 五、验收门（实机脚本）

1. **列表形**：交付节「导入声明」与 WP 卡片入口弹窗均为滚动单选列表（radio+圆点+标题），长列表可滚到底。
2. **候选口径**：只列本工作区会话；其他工作区会话缺席；手动开的自由会话在场可选可抓。
3. **置顶与回退**：绑定会话置顶；归档/离列表的绑定会话仍在列（id 前缀标题）；卡片入口预选 seed 会话。
4. **回归**：无绑定且工作区无可抓取会话时空态提示；粘贴通道照旧；评审导入面零变化；tsc 干净＋全量绿。
