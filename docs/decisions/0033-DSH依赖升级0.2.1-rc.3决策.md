# skyaxis — decision 0033：DSH 依赖升级 0.1.5-rc.2 → 0.2.1-rc.3

> 日期：2026-10-26 · 依据：[upgrade 分析报告](../upgrade/2026-10-26-dsh-0.2.1-rc.3-升级影响分析.md)（research 档）· 拍板：用户 2026-10-26「待拍板决策点都按推荐走」（报告 §四 D1–D4）

## 白话摘要

DSH 宿主升到 0.2.1-rc.3 后，skyaxis 旧 client bundle 的 13 个图标组件名在新模块表里已不存在——插件能加载但渲染即碎，engines 宽域声明反而放行了这种「加载了但坏着」的状态。本决策把全部 `@deepseek-ai/*` 依赖精确钉到 0.2.1-rc.3、engines 收紧到 `>=0.2.1-rc.3`（声明宽度=支持承诺），并吸收 SDK 五条版本线的行为面变化：图标改名、会话列表状态重排（目录改读投影值、主视图会话改看 retainedBy.mainView）、导航动作归视图层 UiWorkspace.openSession、shared.fetch 双参化、zod 双实例对齐。改造是「编译器领着走的小刀」：tsc 四轮把 27 处断点收敛到零，vitest 1258→1262 全绿（+4 条派生判据钉）。

## 一、立项依据（审计报告结论 + 计划期新发现）

- 审计报告（docs/upgrade/）逐符号核验：14 个消费包符号面、子路径导出、patch 清单字段、workspace 注册语义全部存活；硬断点唯一为 ui-primitives 13 个 `Icon<X>Outline<尺寸>` 改名（尺寸后缀→字重后缀 Medium/Regular）。
- 计划期新发现（报告未含，实施纳入）：①`dsh-agent-presets` 包在 0.2.1-rc.3 已拆名（→ agent-preset / agent-preset-registry / persona），devDeps 与 tsdown externals 必须摘除（skyaxis 零 import，纯清单项，属升级必需非清理）；②新 `IconProps` 保留 `size?: number` 覆盖 → 改名彻底机械；③SDK 侧 zod 钉 4.4.3，skyaxis 4.6.5 形成双实例 → ProjectionDefinition 泛型方差编译断裂（TS2322/TS2589 连锁）；④`ConnectionFetchHandler.fetch(request, peer)` 双参化（owner principal 放行）；⑤客户端 `SessionListState` 退役 `subagentsByParent`/`current`（「navigation belongs to view owners」），`SessionSummary` 退役 `completed`、新增必填 `retainedBy`/`blank`；⑥`ISessions.open/openSubagent` 退役，导航归 `UiWorkspace.openSession(target)`（身份或子代理地址单段式）。
- 拍板（报告 §四）：D1 engines 收紧 `>=0.2.1-rc.3`；D2 接受空白会话复用语义+回归钉（agentPreset 隔离为实机冲突后备）；D3 全量精确钉；D4 零引用 devDeps（dsh-commands / dsh-client-ui-sidebar / dsh-client-test-runtime）保留随批升级，清理另立项。

## 二、改动设计

1. **package.json**：25 个存续 `@deepseek-ai/*` devDeps 精确钉 `0.2.1-rc.3`（统一去 `^`）；cordis `^4.0.2 → ^4.0.5`；zod `^4.6.5 → 4.4.3`（对齐 SDK 消灭双实例）；engines.dsh `>=0.1.5-rc.2 → >=0.2.1-rc.3`（D1，与依赖同文件一笔落）；摘除 `dsh-agent-presets` 条目。
2. **tsdown.config.ts**：externals 清单同步摘除 agent-presets 行。
3. **图标改名（13 符号 / 59 用点）**：`Outline14 → OutlineMedium`、`Outline16 → OutlineRegular`（DSH 自家 LanguageRow 用 Regular 先例）；`size={n}` 显式覆盖原样保留。
4. **类型快照三份比对（零漂移，锚注释更新至 0.2.1-rc.3）**：todo-write（DSH todo/tool-todo types 同形）；tool-workflow（线上 `tool-workflow/*` 四字面量仍在——known-event-types.ts:71-74 + dsh ui-workflow-run 同款消费；新包 @deepseek-ai/dsh-workflow 的 `workflow/*` 仅叙述措辞）；open-in-app（三路由值与 choice key 原样，shared.ts 移至 src/）。
5. **connector.ts（任务图重接）**：`subagentsByParentOf`（目录改读 `projectionsBySession[parent].values.subagentCatalog`，宿主 tree.ts 同款，防御性最小形状读）+ `mainViewSessionIdOf`（主视图会话 = `retainedBy.mainView` 计数为正，宿主 DocumentTitle 官方判据；mainView 键由宿主 UI 包声明合并贡献、skyaxis 类型视野不可见，索引防御读）。
6. **register.tsx 导航改道**：open/openSubagent 退役 → `ctx.get('uiWorkspace').openSession(address ?? sessionId)`，ids 诚实门控保留，face 缺席诚实 no-op。
7. **测试面适配**：六文件 `shared.fetch` 单参 → `fetchAs` 包装 + `connection.createPeer({ principal: { kind: 'owner' } })`（dsh fetch-routes 测试同款）；三夹具删 `completed` 补 `retainedBy: {}`；invariants Pick 集同步。
8. **vitest stub 家族 +3**：simple-icons（品牌图标字形）、@deepseek-ai/dsh-util-code-language（代码高亮语言映射）、diff（DiffBlock structuredPatch）——SDK 0.2.1-rc.3 浏览器 bundle 新增未声明裸导入，同 anser/katex 先例。
9. **回归钉 +4**（tests/task-graph/connector-derivation.test.ts）：目录投影派生两条 + mainView 判据两条。
