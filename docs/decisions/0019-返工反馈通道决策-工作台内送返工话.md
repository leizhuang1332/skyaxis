## D1 通道档位 B：工作台内发送（推翻 D2-A 范围=返工话单一动词）

**主路径** = `binding(尾 dev 绑定 sessionId).session.prompt([{type:'text',text}],'queue')`——与 0017 v3 投递直启同一 RPC，差别仅在目标：v3 打进**新建**会话，返工话打进**已存在的** dev 会话（idle 即新一轮输入；running 即宿主原生排队——「排队补话」的本义）。**降级** = prompt 拒/抛/面缺席 → v2 尾巴（input.for(scope).setDraft + open + selectPanel），用户手发兜底——与 [delivery.ts](../../src/client/workbench/delivery.ts) D3 降级逐字同构；conversation 亦缺席 → 诚实失败（复制+跳会话兜底）。

**口径追认**（0017 先例同款）：0007 P0-1 针对的是「替用户按发送」的静默自动化；返工话在 Modal 内**全程可预览可编辑**，点击「发送返工话」=用户对自己预览过的内容显式按下发送——同意权没有旁落。内容基础比投递场景更强：返工理由是用户**刚刚**在拒绝 Modal 里亲手填的结构化账本数据。

**范围钉死**：只动返工话。0016 D2-A 的通用介动词（waiting 应答的 steer/排队补话）与 D9 冻结项不动——D2-A 当时的否决理由（「工作台内排队拆成两半——发得出、看不到回应」）在返工场景不成立：发送后不需要即时回应，正路是会话跑完吐新声明→watcher 收取→收件箱出行（既有闭环全在场）。此论证记档为 D2-B 追认的**场景边界**，不构成通用 B 档解禁。

**探针风险**：v3 刀零实证的是「从未 open 的 created 会话接受 prompt」；本轮新增面是「已存在（可能 idle）会话再次 prompt」。静态基础：同一 RPC、同一 binding 物化路径（[delivery.ts 头注](../../src/client/workbench/delivery.ts) 静态证据链③）。不单设刀零探针——降级尾巴使失败非阻断（诚实降级+复制兜底），实机验收脚本首查覆盖。

## D2 入口位置 C：拒绝时跟进 + 详情常驻

① **拒绝提交成功后**：两处拒绝 Modal（board 卡 [board-section.tsx:224](../../src/client/workbench/board-section.tsx#L224)、WP 详情 [work-package-dialog.tsx:494](../../src/client/workbench/work-package-dialog.tsx#L494)）的提交从 fire-and-forget 改 `await controller.acceptWorkPackage(...)`——返回 ok 才 `onSendRework(wpId)` 弹返工话 Modal（失败/竞态零跟进，状态机不劣化）。② **WP 详情常驻**：验收节标题行「送返工话」按钮，门控=`status==='in-dev' && 尾 acceptance.result==='fail' && 尾 dev 绑定在场（sessions 投影可解析）`——绑定消亡则退役（正路=收件箱「存疑」行的补投）。看板 in-dev 卡**不加**卡面入口（0018「in-dev 及其后无卡面入口」裁定不动）；返工收件箱行列 P4 候选。

## D3 返工话内容 B：结构化组装（纯函数 `buildReworkMessage`）

```
# skyaxis 返工话 <wpId> · <需求标题>

工作包 <wpId> <wp 标题> 验收未通过（第 n 轮验收，n=acceptances.length）。
返工理由：
<尾 fail note>
要求：按返工理由修复本工作包范围内的问题；完成后在回复末尾重新输出声明块（形制同任务书「输出约定」，workPackage: <wpId>），工作台会重新收取。
```

「重吐声明块」指令是 watcher re-seed 链的**必要钩子**（[milestones 0016:99](../milestones/0016-执行实施显性化实施计划.md#L99)：新声明 hash 变→槽重置 pending）——省略则返工闭环断在会话侧行为。Modal 内可编辑（0009 editedText 形制：用户编辑优先于生成内容）。

## D4 补投连带 A：workPackageBlock 附返工历史

dev 任务书工作包信息块（[sow.ts:259-287](../../src/client/workbench/sow.ts#L259-L287)）在覆盖标准后追加：

```
返工历史：
- 第 1 轮 不通过：<note>
- 第 2 轮 通过
```

无 acceptances 零渲染（不污染首投任务书）；纯追加，五段结构与其余块不动。
