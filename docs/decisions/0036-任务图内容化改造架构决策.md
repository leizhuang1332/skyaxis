# ADR 0036 — 任务图 v0.4 内容化改造架构：五层管线与文档层

- **状态**：接受（2026-10-27，用户拍板「待拍板的都按推荐走」）
- **决策者**：skyaxis 团队（lorcan.lei + Claude）
- **前置**：[research 0033 数据源验证](../research/0033-任务图内容化数据源验证.md)（六问五正一负，零阻塞项）
- **关联**：[ADR 0001](./0001-单session可视化v0.1-任务图与subagent子树.md)（v0.1 范围裁定——本决策首次扩其信息覆盖面）、[research 0003 §七](../research/0003-任务图升级数据源验证.md)（P0-P4 路线图——本决策开启 v0.4 新轨道，P2c/P5 门控不受影响）

## 一、背景

用户复盘：任务图立项目标是「一图胜千言」——以图展示 session 会话内容，比翻纯文字聊天记录高效。该目标未达成。缺陷清单（2026-10-27 会话逐条核对代码属实）：

- **信息丢失**：infer.ts 只消费 4 种事件，assistant 产出/工具调用/审批内容全部不进图；user-prompt 只取首条首行 80 字符；失败原因（turn/end.reason 的 LlmFailure 原文）只有 kind 位被读，文案被丢弃。
- **图结构平**：普通会话整图深度约 3 层的线性竖蛇；subagent/workflow 有深度但叶子不承载内容（投影边界：子 session 内部不重建）。
- **单线无因果**：sequence 边明示「非声明式依赖」；任务链与 delegation 子树互不编织（subagent 挂 root，不挂发起它的调用）；无消息明细呈现面（点击 task/user-prompt 节点为空操作）。
- 其余：跨 turn 重复膨胀（todo 身份按 turn 分域，续写列表每 turn 复制一份节点）、无折叠、无筛选/搜索、无时间维度、节点视觉同质、user-prompt 节点 status 语义错位（恒 done/failed）。

根因：ADR 0001 将 v0.1 范围钉在「todo DAG + 血缘拓扑」，内容类（失败 elevation、时间聚合、跨节点聚合、跨 session 视图）全部显式推迟，此后 P2a–P4 工时全花在窄范围保真上，信息覆盖面从立项起一次未扩。管道（懒启动、签名门控、错误边界、诚实规则）扎实，缺的是往图上放什么。

## 二、决策

**任务图 v0.4 范围确定为「拓扑做骨架 + 内容做下钻 + 分层折叠」，架构采用五层管线，核心是在事件与画布之间插入文档层，把「发生了什么」与「怎么画」彻底分离。**

### 2.1 五层管线

```
0 事实层  connector（保留懒启动）→ TaskGraphFacts（事件窗口+list快照+waiting 一体化输入）
1 文档层  document/：events → SessionDocument（turn/task/activity/血缘/workflow 规范化事实
          + ContentStore 明细索引 + 文档签名）
2 投影层  projections/：document + ProjectionOptions → GraphModel（折叠/筛选/详略皆投影参数）
3 布局层  layout.ts：dagre + 签名门控（保留），扩两段布局（组内→组间）
4 视图层  view.tsx：节点渲染注册表 + 明细面板 + 筛选
```

### 2.2 两个关键切分

1. **内容与拓扑分离**：节点只挂 `contentRef`（轻），全文/工具参数与结果/失败原因/waiting 问题文案进 `ContentStore`（重，零拷贝引用 `event.data`），明细面板按 ref 解引用。画布不因大文本变重；内容不改变图结构签名。
2. **边带证据标注**：每条边 `evidence: 'fact' | 'inferred'`——wire 事实（callId 配对、agent-start childId、approval 关联）为 fact，启发式（顺序、时间邻接）为 inferred，渲染面可区分（实线/虚线）。诚实边界从注释搬到用户眼前。

### 2.3 文档层要点

- `TurnDoc[]`：turn 分组（全部 user 消息 refs，非只首条）+ error 原文（`turn/end.reason` 的 LlmFailure/aborted 等 **7 种 TurnEndReason 全息保留**，现状只读 error 一个 kind 位）。
- `TaskDocEntry`：**身份全局化**——`todo-{contentHash}` 去掉 turn 域，同 content 跨 turn 复用同节点原位更新 status（修重复膨胀）；`history` 保留改写史（whole-list 覆盖不再吞历史）。
- `ActivityDoc[]`：assistant-message / tool-call / approval / subagent-spawn / workflow-run，各带 turn 归属 + contentRef；turn 归属对消息/工具事件为 **wire 显式字段**（非环境计数），仅 todo/write 沿用环境回合计数。
- `DelegationDoc / WorkflowDoc`：现 subagents.ts / workflows.ts 的折叠逻辑收编进文档层。
- 文档签名为增量重投影门控；容忍事件窗口前缀截断（`hasMore=true` 时图顶诚实标注）。

### 2.4 投影层要点

- `ProjectionOptions = { fold: { completedTurns, subagentTrees, activityDetail }, filter }`——折叠与筛选都是投影参数，非视图私货；文档签名不变则 memo 命中。
- 委派编织：fact 级（tool/result 文本解析 `started subagent <id>` + catalog 交叉验证）→ inferred 级（同 turn 邻接）→ root 挂接，三级降级链（research 0033 §六）。
- **折叠先聚合节点、后容器嵌套**：折叠产出带聚合徽标（X running / Y done / Z failed——ADR 0001 §七.1 欠账在此偿还）的单节点，点击展开；React Flow subflow 容器 + 嵌套布局留二期备选。
- 节点渲染注册表 `nodeRenderers: Record<NodeKind, Component>`——各类型有形状/图标区分；**user-prompt 节点退役 status 位**。

### 2.5 实施切片

| 切片 | 内容 | 验证结论回写 |
| --- | --- | --- |
| **A 地基** | Facts 形式化；document 骨架 + 签名；身份全局化；task-chain 投影接管 infer（行为对齐测试护送） | 修重复膨胀、user-prompt 状态错位 |
| **B 内容** | activities 进文档；明细面板（assistant 全文+逐消息 provider/model、工具参数/结果/失败原因原文、审批问题文案、waiting 问题、委派 prompt）；evidence 边标注；**耗时徽标**（turn/step/tool 三级，全 fact 派生） | 时间维度解锁（research 0033 §五）；失败原因/审批全量可用 |
| **C 结构** | 折叠策略 + 聚合徽标；详略三档；两段布局；节点渲染注册表 | — |
| **D 编织** | 委派挂接 spawn 上下文（三级降级链）；筛选/搜索走 ProjectionOptions | 编织 fact 级可达（research 0033 §六） |
| **E 打磨** | 手工位置持久化；导出候选 | **chat 锚点退役**（API 缺席定案，research 0033 §七） |

A 为唯一前置；A 落地后 B/C 并行（用户拍板「一起开」）。

## 三、理由

| 理由 | 说明 |
| --- | --- |
| 现架构无处放内容 | 三 builder 直接事件→React Flow 节点，节点 data 是封闭固定形状；不重构则每个新信息类型都要穿透 connector→builder→types→view 四层 |
| 文档层解耦「事实」与「呈现」 | 折叠/筛选/详略全成投影参数；多种视图（全图/概览/时间轴）共享同一文档；内容变更与拓扑变更分别签名 |
| 身份全局化是诚实修法 | todo 续写时 content 字符串不变仅 status 变——精确锚即可合并（覆盖主导模式）；改措辞 = 新节点是诚实行为，不搞模糊匹配暗箱 |
| 聚合节点先行控风险 | subflow 容器 + dagre 嵌套布局是已知难点；聚合节点交付同等信息密度且不押注布局器行为 |
| 全部依赖已验证 | research 0033 六问零阻塞；唯一缺席（chat 锚点）已在切片内退役而非带病假设 |

## 四、数据源验证结论（摘要）

六问五正一负（全文见 research 0033）：①assistant/message 全量可用（turn/step 显式、全文 blocks、逐 step usage、逐消息 provider/model）；②tool 配对 callId 严格、失败原因原文在 wire；③approval 带问题文案/调用关联/四态结局；④**每个事件都有 Unix epoch ms 时间戳**（v0.2 时间欠账全额兑付）；⑤subagent 派生无显式 wire 字段但派生工具结果文本字面含 childId（fact 级可解析 + 防御降级）；⑥**chat 消息级锚点 API 不存在**（E 切片收缩定案）。

## 五、Out of Scope / 不动清单

- **不动**：connector 懒启动生命周期（双标签页教训）、错误边界与 apply 兜底、ids 诚实门控导航、waiting tracker、agent-metrics 投影（root/subagent 的会话级最近一次路由保留现状）、词典三面同步纪律、React Flow + dagre 选型（ADR 0001 §四）、P2c Team 折叠门控（ADR 0002）、P5 迭代布局触发条件（research 0003 §七）。
- **不做**：跨 session 总览（后续 ADR）；AI 摘要式折叠（未来候选，先做机械折叠）；编辑/标注任务结构；模糊任务对齐。
- **退役**：chat 锚点跳转（API 缺席）；todo 身份的 turn 域；user-prompt 节点 status 位。

## 六、影响

新目录 `src/client/task-graph/{document,projections,content}/`；`infer.ts` 的任务链推断逻辑迁移为 document 折叠 + task-chain 投影（行为对齐测试护送），`subagents.ts`/`workflows.ts` 折叠逻辑收编文档层、投影层保留其图构建语义；既有测试随迁移改写为分层测试（document 性质测试承接 invariants 纪律：置换不变、身份稳定、改写史保留）。词典新键随 B/C 面落地，三面同步。
