## 5. 不变约束（新 session 必须遵守）

1. **诚实口径**：无数据不渲染、零值同缺失不占位；built ≠ done（批准拆分/批准计划/验收确认/阶段推进四权永不在 AI 手里）；banner 文案走穷举 switch（`bannerCodeToKey`），不拼键。
2. **protocol 零依赖铁律**：wire 只用手写 guard；host 半 zod 镜像 + 编译期双向可赋值断言同 commit；新字段一律 optional/default + guard 同步放宽（0003 教训）。
3. **词典五处同步**：interface / zh / en / register.tsx LocaleNamespaceMap / register.spec 全量排序哨兵（哨兵清单用 node 脚本从 zh 块重生成，漏一处即红）。
4. **CSS alias-only**（`--dsw-alias-*`；mockup 的 `--state-warn-bg` 等是占位不可搬）；间距/圆角字面 px；`.stageRail` sticky 几何与详情页 `.body` 16px padding 耦合（改一必改二）；横向滚动看板是全设计唯一新增几何。
5. **账本先行**：409 返回时零文件副作用；双写纪律残留方向「有引用无目录」；split 锁覆盖面 = 清单 CRUD + criteria + 生命周期六动作 + 计划写入，门外 = findings / stage / 知识候选（沉淀横贯全周期）；sessions[] append-only 无解绑。
6. **测试惯例**：fireEvent + waitFor（无 userEvent）；fakeController `as never` + overrides 尾参；Modal portal 需 afterEach(cleanup)；MarkdownText 是 stub，断言止于对话框层；RTL 把 U+3000 归一为半角空格（getByText 用半角、accessible name 用原文）；**cordis inject 回调异步落地——真 Context 测试须 await tick**。
7. **批量脚本替换后必须验证命中数**（node replace / sed / perl 静默失配是 P2b 验收断裂的根因）；穿线类改动的回归测试必须经最外层包装渲染（seat 级，直接渲染 Body 抓不到穿线断裂）；实机断点用分段诊断日志三路分流，验收后移除。
