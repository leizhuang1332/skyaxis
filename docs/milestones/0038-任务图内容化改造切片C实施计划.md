## 一、架构裁定（三项）

1. **store 恒全量、view 策略过滤（超集原则）**：task-chain 投影恒发活动节点全量（`activity:{seq}`，id 域与既有命名空间不相交）；新增 `projections/view-policy.ts` 的 `applyViewPolicy` 在视图侧统一应用 { hideFailed（P3 收编）、activityDetail 三档、collapseCompletedTurns、collapsedSubtrees }。折叠态是纯视图态——切换零延迟、不回连 connector。
2. **折叠 = 三件事**（聚合节点方案，subflow 容器留二期）：①`collapseCompletedTurns` 工具条开关——已收场且 reason=completed 的轮次折成单 `turns:completed` 节点（**error/aborted 轮不折——卡点永远可见**），边端点统一重缝映射+去重；②`collapsedSubtrees` 逐节点（subagent 面板按钮）——沿 delegation 边传递闭包丢后代（member 再父化后代含在内——闭包跟边不跟类型），根挂徽标（后代状态计数，多子树各自计数不串）；③`activityDetail` 三档——`none`（默认=B 现状）/`notable`（**卡点**：错误工具+审批+委派；on-demand 的落地定义）/`all`；notable 档按文档 turn 重建保留活动的链（断链重缝，顺序来自文档 key 序）。
3. **投影 memo（文档签名兑现·引用同一性实现）**：connector 按 `window.entries` 引用 + root 事实（label/rootStatus/rootMetrics）同一性缓存 fold+task-chain 产物——list 重推路径不再全量重折叠；事件窗口每次发布都是新数组，流式路径天然 miss（语义等价签名 memo、零字符串比较）。
