## 实机验收脚本（7 步，待用户）

1. **就绪区**：有未裁决提议/未答澄清/未处置发现的需求 → S1 顶部 warning 计数行；AI 报告带 `stageReady: true` 收取后出 success 咨询行（与计数行可并存）。
2. **定稿流**：[定稿需求理解]（S1 底部与 [完成本阶段 →] 并排）→ ack Modal 统计四段与警示行 → 勾选确认 → 横幅「需求理解已定稿 · <日期>」+ [撤销定稿]；零记录需求不出现按钮。
3. **变化提示与撤销**：定稿后再收一份新报告（或采纳一条提议/回答一条澄清）→ 横幅追加「定稿后上游已变化」；[撤销定稿] → 确认 → 戳与横幅消失，可再定稿；再定稿后原横幅日期更新。
4. **摘要导出**：[导出理解摘要] → Modal 预览（定稿状态行/标准/发现三组/已答/未答澄清带推荐答案）→ 下载 `understanding-sheet-<rid>.md` + 复制；全零内容按钮禁用。
5. **拆分任务书九节**：② 探索规划 [生成拆分任务书] → 预览九节结构（`# skyaxis 拆分任务书 · <标题>` 起头）；PRD 路径引用 + 重点章节指针（正文零嵌入）；需求快照含**定稿状态行、发现处置结论（已解决带方案）、已答澄清**；declare 骨架逐字照旧（knowledge + stageReady）。
6. **stale 两新臂**：已定稿需求批准拆分 → 撤销重定稿（或回答一条澄清）→ S2 出「上游已变更」徽章，成因分别为「理解已重新定稿」「澄清答案已变化」；[确认仍有效] → 两臂重锚消失；无定稿需求批准后不动 → 两臂不误报。
7. **回归**：dev/review 任务书五段逐字不变；S5 导入声明零感知新字段；advanceStage 行为不变（未定稿可推进、推进不自动定稿）；双窗口 409 收敛；刷新后戳/基线/横幅状态保持。
