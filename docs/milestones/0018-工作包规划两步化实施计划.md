# 工作包规划两步化实施计划（wp-plan 任务书 / plans[] seed / 状态驱动分层）

> 日期：2026-10-20
> 依据：[决策 0018](../decisions/0018-工作包规划两步化决策.md)（D1-D8 全采推荐档——用户 2026-10-20）。
> 定位：wire+host+client 三面中轮（协议小扩：新 purpose/新目录常量/可选字段/新 action）。**底线两刀=刀一通道与账本+刀二 UI 分层（独立可验收，刀三可砍——砍刀保险）**。
> 基线：起手 1152 tests（0017 收口后；词典键数刀一实施时记账）。

## 总体形状（先立边界）

```
刀一 通道与账本：wp-plan purpose 九节任务书 + .skyaxis/wps/<wpId>/plan.md 通道
    + watcher/seed→plans[] v=max+1 + planSeed 哈希主锚 + 投递回传记 session
刀二 UI 分层：待计划主动作=规划任务书（board/详情/inbox 三面）
    + dev 直投 ack + 来源会话行 + 计划节回显验收
刀三（可选，触发条件立项）：驳回循环增强（重生成任务书嵌被驳回尾草稿参考）
    + 工作区路径披露行 + 失效链接入评估
不变：四权、硬门①②语义、dev/review 五段+revision 戳、declare 家族、
    sessions[] 绑定、advanceStage、S5 导入面、失效链（继续挂账）
```
