## 实机验收脚本（刀一后）

1. **返工话主路径**：built 卡拒绝（填理由）→ 拒绝 Modal 关闭后**自动弹返工话 Modal**（理由已在文中）→ 编辑一句 → 发送 → dev 会话（宿主侧）出现该消息并开始跑。
2. **降级路径**：宿主忙/异常时发送 → 诚实降级（跳会话页带草稿）或失败 alert+复制兜底——不静默。
3. **详情常驻入口**：同一 WP（in-dev+尾 fail）重开详情 → 验收节「送返工话」仍在，可再发（补话）；尾验收为 pass 或绑定消亡时按钮退役。
4. **re-seed 闭环**：dev 会话修完末尾重吐声明块 → 收件箱「完成待验收」出行 → 导入 → built → 再验收通过——0016 脚本第 4 条全链走通（此前断在手动补话）。
5. **补投连带**：同一 WP 走补投（生成工作包任务书）→ 任务书工作包节出现「返工历史：第 1 轮 不通过：…」。
6. **回归**：投递直启/补投/重规划/markBuilt/收件箱两组/看板卡动作全部照旧；首投任务书（无 acceptances）零返工历史节。
