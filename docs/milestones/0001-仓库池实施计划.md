# 仓库池（repos pool）实施计划

> 日期：2026-09-24
> 依据：[调研报告 0004](../research/0004-仓库池调研-DSH宿主能力评估与方向规划.md) + [决策 0003](../decisions/0003-仓库池P0决策-路线B专属repos-yaml与校验策略.md)
> 定位：大方向与步骤清单，不含实现细节；每阶段末给出验收口径。架构总形：**宿主半（存储 + 校验 + 端点）+ 浏览器半（UI）**，双面插件既有范式内扩展，不改宿主。

## 总体形状（先立边界）

```
浏览器半  src/client/repos-pool/{register,view,store,dictionary}   UI、CRUD 流、放行确认
宿主半    src/index.ts 扩展 + src/repos-pool-host/{repos-file,validator,endpoint}（目录名实现期定）
数据      $DSH_HOME/skyaxis/repos.yaml（专属文件，自带 yaml 依赖）
通道      connection.fetch.register 的 /api/skyaxis/repos 端点族（list/save/remove/validate）
```

硬约束（全程有效，源自调研）：`panellist id === main key`；不注册 `main.conversation`；CSS 只用 `--dsw-alias-*`（禁字面色/static 色/dark 选择器/组件库）；`ext::`/`fd::`/`file://` 必拒；未知失败必拒。

## P0 PoC（验证路线 B 的四个未实证环节，全部通过才进 P1）

> **2026-09-24 已完成：五项全部通过**，明细见 [PoC 结果报告 0005](../research/0005-仓库池P0-PoC结果报告.md)。P1 可启动。

- [x] **PoC-1 子进程校验链**：✅ 5/5 场景（真实网络/git）。关键发现：凭据必须中和（`-c credential.helper=` + `GCM_INTERACTIVE=never`，`GIT_TERMINAL_PROMPT=0` 挡不住 GCM）；Windows taskkill 终止 = 非零退出 + 空 stderr → 网络类；GitHub 401/404 混淆双形态均归权限类。
- [x] **PoC-2 端点回环**：✅ 7/7。Leg A 官方直构（fetch.register→createSharedFetchHandler 派发 200/404/dispose）；Leg B 真实 HTTP（webserver+credentials 临时 DSH_HOME）：无 cookie 401、跨站 Origin 403。带 cookie 同源 200 全链路归 P1 实机验收。
- [x] **PoC-3 yaml 自管文件回环**：✅ 11/11（原子写、.bak 备份、坏文件降级不抛、坏文件拒写保护现场、陈旧 revision 拒绝）。
- [x] **PoC-4 ui-primitives 接入**：✅ 四分证据（PLATFORM_MODULES+build 通过 / 已发布 web shell 静态表命中 / PoC-5 运行时导入渲染 / typecheck）。浏览器内 loader 应答归 P1 实机。
- [x] **PoC-5 组件测试样板**：✅ 3/3（全量 81 tests 无回归）。边界发现：官方 SlotTestRuntime 与 /client 浏览器工厂在 monorepo 外不可用 → 完整外壳测试走实机；已落地长期测试基建（真 SlotCore 契约测试 + ui-primitives 依赖 stub + vitest alias）。
- [x] 失败处置：未触发。

## P2 数据层与校验（核心功能）

- [ ] 宿主半 repos.yaml 模块：schema（zod）+ 读边界校验、原子写 + 备份、自建 revision、坏文件降级（空列表 + 用户提示，绝不炸宿主半）。
- [ ] 宿主半校验器：合法性（D2 白名单 + scp 歧义防护，实现期定规则）→ 可达性（git 在：ls-remote 三态；git 缺失：跳过并返回「未验证」标记位）。
- [ ] 端点族 `/api/skyaxis/repos`：list / save（含校验结果与 revision）/ remove / validate。
- [ ] 浏览器半 CRUD 流：添加/编辑（Modal 表单，名称/URL/简介，简介为自建 token 化 textarea）→ 校验反馈（红字 + Tag）→ 网络或权限失败走 `RiskConfirmation` 确认放行、未知失败硬拒、不合法硬拒 → 保存持久化。
- [ ] **验收**：增删改查全链路持久化；四类失败路径行为符合 D2/D3/D4；并发双开页写冲突被 revision 拦截；手改坏 repos.yaml 后插件仍可加载。
