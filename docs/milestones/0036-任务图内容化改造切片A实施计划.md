## 二、语义变更清单（行为对齐测试显式记录）

| 变更 | 旧行为 | 新行为 | 钉住用例 |
| --- | --- | --- | --- |
| 跨 turn 同 content | 每 turn 复制节点（竖蛇按 turn 数倍增） | 一个节点 + 逐 write 修订史 | task-chain「reuses one node per content across turns」 |
| 最新 write 缺席 | 仅同 turn 内退役，跨 turn 残留 | 全局退役（历史保留在文档），再出现复活 | task-chain「retires…/revives…」 |
| user-prompt status | 恒 done/failed | 无 status 位（turn 失败仍如实升级未完成任务） | task-chain「retires the status bit…」 |
| task 节点 id | `todo-{turn}-{hash}(#N-1)` | `todo-{hash}(#N)` | task-chain「turn-free」 |
| 跨 turn 链边 | 显式「上 turn 末 → 下 turn 首」边（turn 域节点下成立） | 共享节点天然衔接；换血列表时旧节点退役不留悬挂边；回头边无环守卫丢弃 | task-chain「chains through SHARED nodes / no dangling spine / no back-edge」 |
| turn/end reason | 只读 error.kind 一个位 | 七种 reason 全息保留在 TurnDoc | fold「records all seven turn/end reason kinds」 |

节点 id 格式变化无持久化依赖（手工位置为会话内存态）。
