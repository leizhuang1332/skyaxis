## 实施记档（单工作树交付）

### 刀一 [sow.ts](../../src/client/workbench/sow.ts)

- `INPUT_INSTRUCTION` 常量（阅读纪律括注，九节/五段头共用）；`INPUT_NOUN` 全 purpose 表 + `BASELINE_CONSUMER`/`BASELINE_FALLBACK` 两张 Partial 表（dev=本工作包/本次开发，review=本次评审×2）。
- `analysisInputBlock(ctx, header)`：签名加 header；基线臂从 `split || plan` 扩为 noun 表在场即走（dev/review 同三态诚实行）；repos 行与结尾指令原样（dev/review 落「向用户报告」臂）。
- `buildSow` 五段路径：`[需求] → [输入] → [工作包]（dev）→ [知识注入] → [输出约定]` + 戳；prdBlock 调用与函数体删除；四个九节 caller 改传 `## 输入${INPUT_INSTRUCTION}`。
- 退役：`splitPrdSections` + `PrdSection`（唯一生产消费者已亡）、`SowContext.prdSections`/`prdDocumentName`、`PREAMBLE_HEADING`。

### 刀二 [sow-modal.tsx](../../src/client/workbench/sow-modal.tsx)

- 左列 PRD 组 JSX 整块删除（组题/加载/空/失败提示/select/章节 checkbox）；左列只剩 knowledge 组 + dev 工作包范围组。
- 状态退役：`prdError`/`docName`/`sections`/`checkedSections`/`toggleSection`/`loadDoc`/`defaultPrdText`/`fetchPrdText` prop；`prdSeqRef` 保留（列表失效守卫仍在用）。
- 开面 effect：无 PRD 面臂 `purpose !== 'analysis' && purpose !== 'consolidate'` 即 return；列表失败不再置组内错误态（组已亡，prdDocs 停留 null ⇒ 输入段诚实行「列表未可得」）。
- preview：`analysisPrdDocs` 仅 analysis/consolidate 传；`analysisRepos`/`analysisUnknownRepos` 改全 purpose 无条件传（六 purpose 输入段都吃 repos 行）。
