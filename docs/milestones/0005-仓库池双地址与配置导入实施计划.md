## 总体形状（先立边界）

```
改动主轴  RepoRecord 单 url → urlSsh?/urlHttp? + per-address 状态四件套（决策 0004 D1/D2）
存储      repos.yaml version 1→2（读侧兼容迁移，写侧恒 v2；持久化机制零改动）        P1
host 半   types/endpoint 改造 + 新增 import 端点（第五端点）；validator 零改动        P1/P2
浏览器半  repo-form 重写（双地址+并行验证）+ list/view 双地址展示 + 导入 UI           P3
连带      requirements 详情页 picker 地址推荐/切换（0002 边界不动，wire 零改动）      P4
不变      protocol.ts 零依赖铁律、三处对齐防线、乐观锁、原子写、degraded 拒写、D2 白名单
```

**硬约束（全程有效）**：三处对齐防线不可绕过——① `types.ts` ↔ `protocol.ts` mutual-assignability 编译断言（原子同改）；② `dictionary.ts` ↔ `register.tsx` LocaleNamespaceMap zh/en 键集镜像；③ browser 手写 type guard 同步。导入路径逐地址过 `checkUrlSyntax`，不得成为白名单后门；所有写路径（save/remove/import）复用 `ReposFileStore.save` 乐观锁通道；`classifyLsRemote`/`substantiveStderr` 导出签名不可动（clone.ts 依赖）；requirements host 不读 repos.yaml（0002 边界）；CSS alias-only；文案中文默认。

## 集成策略与发布口径

> **2026-09-27 实施修订**：原"P1 结束编译断、P1–P3 同分支不可分段 commit"的表述不可执行——本仓每阶段直接 commit main 且工作树必须全绿。修订为：**每阶段独立全绿 commit**（P1 含 host save 语义与双半形状适配以达成全绿，见 P1 节修订块）；"一次发版"约束不变——**P1–P3 期间 main 不发版**（旧 client 在 list 解析即失败，非 save 422；缓存窗口仅最终发版瞬间且两半同包覆盖，见决策 0004 连带影响更正）。

- **v2 落盘后不支持降级**回旧插件（`.bak` 为单份滚动备份，第二次保存即覆盖 v1 锚点）——发版说明显式声明（决策 0004 D3）。

## 风险登记（方向级）

| 风险 | 缓解 |
|---|---|
| v1→v2 迁移零先例，坏迁移=存量数据"看起来消失" | 迁移矩阵测试先行（四 kind + 语法非法存量 + 纯空白 + revision 保留）；"格式转换不做内容审查"裁决兜底；.bak 存在性报告 |
| per-address 协议面积大（字段 7→11+），三处对齐防线漏改 | 编译断言 + 键集断言自动暴露大半；field 定位链等无兜底项列入 P3 验收 |
| 双地址验证交互（双 gate 混合态、并行探测）复杂 | 并行 validate + 结论收口后解锁提交；gate 注明槽位；repo-form 用例按地址扩编 |
| 导入合并边界多（同名多条/跨槽撞车/批内同名/空值） | 决策 0004 D6 全矩阵逐条落测试；报告四计数可对账 |
| clone 地址选择回归（双地址反而不可用） | per-address 结论推荐 + 可切换（决策 0004 D7）；实机验收第⑥项专项 |
| 浏览器 bundle 引入 yaml（违反零依赖铁律） | 文件解析只在 host 半；前端仅 `file.text()` 上送字符串 |
| 导入大文件内存峰值 | 前端 file.size 预检 + host 先长度后 parse + 自设上限 413 |
