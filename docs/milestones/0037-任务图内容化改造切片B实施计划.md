## 一、范围裁定（四点）

1. **画布拓扑不变**：不新增画布节点类型（activities 上画布是 C 的活）；B 加「面板 + tooltip + 边样式」三个呈现面。
2. **耗时口径**：turn 时长（user-prompt 节点 `durationMs` + tooltip + 面板）、工具调用时长（面板活动行）、workflow run 时长（run 节点 + 面板）——画布 label 不塞时长。
3. **点击语义变更**：任意节点单击 = 打开明细面板；subagent/member 导航收进面板「打开会话」按钮（原单击直跳退役）；P3 defpanel 并入明细面板（definition 成为 run 面板 section）。
4. **evidence 边标注**：`TaskEdge.data.evidence`——sequence=inferred（虚线）、delegation/workflow/phase=fact（实线），画布左下图例。

## 三、行为变更与诚实边界

| 项 | 说明 |
| --- | --- |
| 单击导航 → 面板 | subagent/member 点击不再直跳会话；导航按钮在面板内（ids 门控不变） |
| spawn 判定 | 文本 + catalog 双过关 = fact；任一不过不标（不臆造）；工具名不参与（可配置，research 0033 §六） |
| 孤儿/重复事件 | 孤儿 result/decided 诚实跳过；重复首胜（幂等，签名不变） |
| turn 归属双源 | assistant/tool 用 wire 显式 turn（fact）；approval/todo 用环境计数（payload 无 turn） |
| 时长 | 全部 fact 级（事件 time 派生）；未收场 turn/run 诚实缺省 |
