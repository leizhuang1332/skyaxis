## 路线决策记录（本次调研核心产出）

六个候选横向对比（main 第二 entry / 面板内子视图 / Modal / 右栏 tab / shell.overlay / 内联展开），结论 **B > A > C**，决定性证据：

- **生态零先例**：DSH 生态注册过 main entry 的只有宿主自己（conversation，ui-conversation/apply.ts:391）与 skyaxis（repos、requirements）。dsh-web-ui 全仓 20+ 插件零 main 注册——"列表→详情"先例（skill-explorer、dsh-market 等）全部走容器内导航（面板内 tab / Modal / settings 分页 / 自建槽位 / createRoot 自造 overlay）。
- **宿主官方心智是 B**：宿主自己的会话树（会话→子会话 lineage）就在 `main.conversation` 单 entry 内实现，不是多 main key。main key = 顶层面板，层级导航在面板内部。
- **A（main 隐形 entry）的后患随页面数复利**：侧栏高亮缺失（activePanelId 严格相等匹配）、"main entry 数 ≠ 侧栏按钮数"漂移、activePanelId 语义超载（宿主未来若加持久化/URL 同步，隐形 key 是边角案例）、rc 阶段宿主升级需专项回归。每加一个带详情的页面，税按比例放大。
- **B 的迁移出口干净**：日后若出现"任何位置直达需求详情"的深链需求（A 的唯一独有收益），迁移面 = register.tsx 加第二 main entry 挂 detail.tsx + openDetail 追加 selectPanel + 返回动作改 selectPanel；detail.tsx / selectedId / controller 动作全部原样复用（约半天）。

### 调研结论（tab 能力盘点，2026-09-26 实证；2026-09-27 二轮补 conversation.view 解剖并修正设计）

| 项 | 结论 |
|---|---|
| primitives 有无 Tabs 组件 | **无**。类型入口全量盘点（`dsh-client-ui-primitives/lib/types/index.d.ts`）：Button / Input / Menu / Modal / Switch / Tag / Pill / StateDot / DisclosureRow / HoverCard / Tooltip / Toast / RiskConfirmation / OnboardingSurface / ConnectionIndicator / JsonTree / Terminal·Read·Diff·Search·Web·Code·Json Block / MarkdownText + 60 图标 + 工具函数——无 Tabs / TabList / Segmented |
| **conversation.view 解剖（宿主官方 tab 模式）** | 三件套，**同样无可复用组件**：① 槽位声明 = list slot / **session scope** / 由 `conversation.session` 的 children 声明（apply.ts:263）；② tab 投影 = 宿主从 entries 投影 `{id, label}`（`resolveSlotLabel` 吃词典 thunk）存 snapshot store，订阅 slot + locale 刷新（apply.ts:140-195）；③ 切换器 UI = `ConversationSessionHeader` **自绘** button（`role=tablist/tab` + `aria-selected`，`tabs.length > 1` 才渲染，**无箭头键盘导航**，ConversationSession.tsx:140-155）；④ 内容 = `renderSlot('conversation.view', props, { only: active.id })` 按活动项挂载；⑤ 选中态 = conversationStore.view 持久化 + 兜底 `chat`，"绝不自动选第一个注册项" |
| 宿主 tab 视觉基线（中央面板） | **ui-conversation 会话页视图 tab**（ConversationRoot.module.css:159-205）：**文字 + 底部 2px 蓝条**式——13px/16 wt500 文字、tertiary 色、strip gap 36 / padding-left 8 / margin-top 10、active 色 `--dsw-alias-state-business-primary`（业务蓝，两主题恒蓝）+ `::after` 2px 底条盖 header 发丝线；**tab 行在 header 内**（76px 构成本就含 tab 行：10 顶 + 30 标题 + 10 margin + 16 tab + 9 底） |
| （对照）右栏 tab 基线 | ui-dockkit 胶囊 chip（28px r12 / `markdown-tag` 填充）——**dockkit 场景专属**，非中央面板基线（2026-09-26 初稿误选，27 日修正） |
| 生态 tab 先例 | skill-explorer 面板内 tab 为**自绘**（`role="tab"` + 自写 css，无组件）；**插件声明自建槽位**有实证先例：preset-center 的 `dsh-workshop.panel`（keyed, root，插件间共享面板壳）——skyaxis 声明 `requirements.detail.view` 同构可行 |
| **路线结论** | **复刻 conversation.view 模式**（非仅自绘注册表）：声明自有 list slot + entries 投影 + `renderSlot({only})` + tablist 照会话页逐字移植——与宿主官方 tab 同构，且获得跨插件开放性。tab 本体仍无组件可 import，复用的是**模式与视觉基线** |

### 设计（B 路线不变；slot 化视图注册，2026-09-27 修订版）

```
RequirementsPage（挂载点不变；宿主半 / 协议继续零改动；register.tsx 仅加槽位声明）
├─ header 详情态：[← 返回] + titleCluster（标题 / 描述）
│                + tab 行（titleCluster 下方，照会话页 tabs 块——底条压发丝线）
│                    ├─ 「概览」overview      ← 占位 seat
│                    └─ 「占位」placeholder   ← 占位 seat
└─ body
    └─ renderSlot('requirements.detail.view', { t, requirement }, { only: activeId })
        └─ 活动 tab 的组件（session 内仅挂载一项，同 conversation.view）
```

- **自有槽位声明**：`'requirements.detail.view': { kind: 'list'; scope: 'root' }`（SlotMap 本地 declare 合并，同 main/panellist 先例；register.spec 的 mountFixture 补声明）。
- **tab 注册 = slot 注册**：apply 时 `ctx.slots.register({ name, id, order, label: () => t(key) }, Component)`——条目是组件而非 render 函数，label 走词典 thunk（宿主 locale 切换自动重解析）。skyaxis 自有的两个占位 tab 在 register.tsx 与主面板同批注册、随 disposer 撤销。
- **消费者在 detail.tsx**：`ctx.slots.entriesOfSlot('requirements.detail.view')` 投影 tabs（+ subscribe 刷新，照 apply.ts:140-195 形状）→ 自绘 tablist（结构/样式/行为照 ConversationSession.tsx:140-155 逐字移植）→ `renderSlot(..., { only: activeId })` 挂载活动项。**加功能 tab = 加一个 slot 注册项**，detail.tsx 不随 tab 变；**其他插件未来也可注册进该槽位**（跨插件开放，slot 机制本意）。
- **tab 行位置**：header 内 titleCluster 下方（会话页同位）——strip 常驻问题自然消解（header 本就 flex:none），header 高度自适应（tab 行 ~26px，短记录仍近 76px 基线）；缺失态不渲染 tab 行。
- **tab 态**：组件内 `useState`（详情会话生命周期，进新需求重置）；不做持久化。**默认选中策略对齐宿主**：不自动选第一个注册项——无有效选中时回落首 tab 并显式置为选中（与宿主"persisted → chat fallback"的差异在无 chat 等价物，文档记录）。
- **a11y 对齐宿主**：`role=tablist/tab` + `aria-selected`，**无箭头键盘导航**（宿主未做，同构优先；后续要加是 detail.tsx 内十行的事）。
- **占位内容**：notice 卡（P1 缺失态同形态，CSS 类合并为 `detailNotice`）+ 词典"功能规划中，此页预留。"
- **词典 +3 key**：`detail.tab.overview`（概览 / Overview）、`detail.tab.placeholder`（占位 / Placeholder）、`detail.tab.seat`（功能规划中，此页预留。/ A planned feature will land here.）
