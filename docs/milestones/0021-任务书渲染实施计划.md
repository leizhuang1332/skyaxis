## 实机验收脚本（刀一后）

1. **渲染面（用户反馈主场景）**：任一需求打开七种任务书（分析/拆分/规划/需求整理/评审/工作包规划/dev）→ 右栏默认渲染 markdown（标题为标题层级、列表/表格成形、代码块带复制钮），无 `#`/`**` 原文。
2. **切换面**：点「编辑」→ textarea 原文编辑；键入后切「预览」→ 渲染反映编辑；再切「编辑」→ 编辑保留；重开弹窗 → 恢复渲染默认＋生成内容重建。返工话弹窗同验。
3. **投递面**：dev 任务书投递后宿主会话 fallback 标题头行无 skyaxis（`# 工作包任务书 WPn · …`）；复制按钮粘出的仍是 markdown 源码。
4. **存量兼容面**：投递前已存在的旧标题会话（`# skyaxis 工作包任务书 WP1 · …`）在 idle 翻转后仍自动绑定、seedDevDeclare 仍可修复。
5. **回归**：投递/降级/绑定/收取、返工话发送、收件箱动作、计划版本链照旧。
