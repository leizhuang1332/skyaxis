## 实机验收脚本（6 步，用户 2026-11-03 实机验收通过）

1. **from 臂（主体）**：留空 branch 默认、from 填仓库真实存在的分支（如 product）关联克隆 → 完成后 `<workspace>/repos/<目录>` 内：`git branch --show-current` = 开发分支名；`git rev-parse HEAD` == `git rev-parse origin/product`；**`git rev-parse --abbrev-ref @{upstream}` 报 no upstream**（`--no-track` 钉死项）；`git branch -vv` 无 `[origin/…]` 方括号。
2. **跟踪臂优先**：关联克隆一个远程已有同名开发分支的仓库，from 随意填 → 照旧跟踪检出（HEAD==origin/<branch>、upstream 在场）——0011 无回归。
3. **留空回归**：from 留空 → 与现状零回归（`-b` from HEAD、无 upstream）。
4. **远端无 from**：from 填不存在的分支 → 克隆完成后 failed（bad-branch）、行状态 detail 透出 git 首行（含 `origin/<from>` 字样）、repos/ 半成品目录被清。
5. **preflight**：from 填非法名（如 `bad..name`）→ 立即 inline「分支名不合法」、零克隆、ledger 无脏行。
6. **reclone 与旧档**：带 from 的关联重克隆 → 以 ledger 的 from 为起点重跑；旧 requirements.yaml（无 fromBranch 字段）照常加载、已关联行无后缀；modal 重开 from 恒空（branch 照旧 carry-over）。
