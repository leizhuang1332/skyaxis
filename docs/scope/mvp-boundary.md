# skyaxis — MVP 边界（权威出处）

> 本文档定义 skyaxis MVP 第一版的边界：**In-Scope（做什么）+ Non-Goals（不做什么）**。任何对 MVP 边界的修订，必须先开 ADR，再回写本文档。

**锁定来源**：[ADR 0005 — MVP 边界与 Non-Goals](0005-MVP边界与Non-Goals.md)（2026-09-19 接受）。

---

## In-Scope（MVP 必须包含）

| 维度 | 决策 | 来源 |
| --- | --- | --- |
| **宿主** | deepseek-harness（DSH）的独立插件 | [ADR 0001](0001-形态-dsh插件.md) |
| **形态** | 插件（不是独立产品） | [ADR 0001](0001-形态-dsh插件.md) |
| **定位** | AI 编程可视化插件 | [ADR 0002](0002-定位-可视化向.md) |
| **场景** | A / B / C / D / D1 / D2 共 6 个 | [ADR 0003](0003-MVP场景清单.md) |
| **核心画像** | A（AI 重度多 session 用户） | [ADR 0004](0004-目标用户画像.md) |
| **运行环境** | 纯本地 + 单端（不联网 / 不多端） | 本轮决策 |
| **分发** | MIT 开源免费 | 本轮决策 |

### 6 个场景简述（来自 ADR 0003）

| # | 场景 | 在 MVP 中的角色 |
| --- | --- | --- |
| **A** | 单 session 内进度可视化（任务树 / 时间线 / 进度条） | 核心 |
| **B** | 跨 session 产出聚合可视化 | 核心 |
| **C** | 多 session 总览与状态可视化 | 缓解（命中"多 session 心智爆炸"痛点） |
| **D** | session 决策 / 代码片段归档与检索（**只读归档 + 全文搜索**，不含语义级检索） | 增强（从暂缓项提升） |
| **D1** | session 内 task DAG | A 的增强 |
| **D2** | session 间输入 / 输出依赖图 | B 的增强 |

## Non-Goals / Out-of-Scope（MVP 明确不做）

### 场景层 Non-Goals

- **D3**：session 间文件 / 模块冲突视图。**来源**：[ADR 0003](0003-MVP场景清单.md)。
- **D4**：跨项目 / 跨仓库依赖。**来源**：[ADR 0003](0003-MVP场景清单.md)。
- **C 方向完整版**：跨 session 知识沉淀 + 语义级智能检索。**来源**：[ADR 0003](0003-MVP场景清单.md) / [ADR 0002](0002-定位-可视化向.md)。
  - **说明**：D（session 决策 / 代码片段的**只读归档 + 全文搜索**）属于 MVP；语义级检索不属于。

### 画像层 Non-Goals（Anti-Persona）

- **反例 1：团队协作用户**。**来源**：[ADR 0004](0004-目标用户画像.md)。
- **反例 3：跨项目独立 session 用户**（B 画像）。**来源**：[ADR 0004](0004-目标用户画像.md)。
- **学习者 / 探索性使用**：MVP 不为这类用户做**专属优化**，但他们使用 skyaxis 不会被劝退。**来源**：[ADR 0004](0004-目标用户画像.md) 边缘画像。

### 运行环境 Non-Goals

- **不做云端同步**：session 数据 / 归档数据 / 配置都只存本地。
- **不做多端同步**：仅支持单台设备，不支持手机 / 平板 / 另一台电脑。
- **不做手动云备份**：MVP 阶段不引入任何云端能力。
- **来源**：本轮决策（2026-09-19）。

### 分发 / 商业 Non-Goals

- **不闭源**：必须 MIT 开源（与 DSH 宿主一致）。
- **不收费**：核心功能永久免费。
- **来源**：本轮决策（2026-09-19）。
